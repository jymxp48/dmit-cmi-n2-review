## CMI 回程是什么，为什么值得单独说

先简单解释一下背景，不然后面的套餐对比看起来会很懵。

CMI 是中国移动国际（China Mobile International）的骨干网络，走的是移动的国际出口。N2 这个命名是 DMIT 内部的线路分级，代表的是双向 CMI 优化——去程和回程都走移动的骨干，不绕路，延迟相对稳定。

很多便宜 VPS 的问题不在于带宽，而在于回程。去程可能走直连，但回程绕了一大圈，晚高峰一到，延迟从 150ms 飙到 300ms 以上，丢包率也跟着上去。CMI N2 的优势就在这里——回程有保障，不是那种"运气好的时候快，运气不好就拉胯"的状态。

当然，CMI 不是 CN2 GIA，两者不是同一个体系。CN2 GIA 走的是电信的精品网，CMI 走的是移动的骨干。对于移动和联通用户来说，CMI 的体验通常比 CN2 GIA 更好；电信用户则相反。这个要根据自己的运营商来判断。

## 实际延迟表现，说点具体的

我测过几次，洛杉矶 CMI N2 回程到国内的延迟，移动用户大概在 150-170ms 左右，联通稍高一点，电信用户的体验会因为走的不是 CN2 而有所差异。

晚高峰（晚上 8点到 11 点）是最能看出线路质量的时间段。普通 VPS 这个时间段延迟会明显抖动，CMI N2 的表现相对稳定，不是说完全没有波动，但不会出现那种突然跳到 400ms 的情况。
